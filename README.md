# Krupa Jaiswal: Personal Portfolio

A hand-coded personal portfolio built for the Personal Portfolio Website assignment.

- **Stack:** plain HTML, CSS and JavaScript (no frameworks, no build step, no no-code builders)
- **Hosting:** Vercel (free default URL)
- **Sections:** About, Projects & work, Skills & interests, Contact
- **Responsive:** single-column layout on phones, no sideways scrolling

## Design notes

The page is built to feel like one of my paintings: a teal wall with an arch taken from my Radha-Krishna canvas, a pale yellow floor with a lattice border, and a lilac-to-peach sky inside the arch. The rest of the page sits on a lilac canvas texture with brush-stroke underlines. The "lens" switcher in the header is a small interactive touch based on how I describe myself: analyst, organiser and people-reader.
